Failure output:
- If no tag is found, emit exactly one failure row for the place using its first target_tag.

- Use PAGE_UNAVAILABLE when plausible pages exist but cannot be opened.
- Use NO_FEATURE_EVIDENCE when identity is verified but no exact sentence supports any target_tag.
