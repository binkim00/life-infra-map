# 🗺️ 상황 기반 생활 장소 추천 지도 서비스

## 📌 1. 프로젝트 소개

본 프로젝트는 사용자가 현재 위치 또는 특정 지역에서 필요한 장소를 상황에 맞게 추천받고, 추천 결과를 지도에서 확인할 수 있도록 돕는 서비스입니다.

공중화장실, 주차장, 흡연구역, 무료 와이파이, 공원, 쉼터와 같이 생활 속에서 자주 필요하지만 일반 지도 서비스에서 한눈에 확인하기 어려운 정보를 외부 데이터 기반으로 제공합니다.

또한 조용한 카페, 산책하기 좋은 장소, 드라이브 목적지, 야경 보기 좋은 장소처럼 사용자의 목적과 상황에 따라 필요한 장소를 추천할 수 있도록 장소별 카테고리, 태그, 위치, 최신 확인일, 신뢰도 정보를 함께 활용합니다.

단순한 지도 검색 서비스가 아니라, 사용자의 현재 상황을 분석하고 적합한 장소를 추천한 뒤, 추천 결과를 지도와 목록으로 확인할 수 있는 상황 기반 장소 추천 서비스입니다.

---

## 🎯 2. 서비스 목표

- 사용자의 현재 위치와 상황에 맞는 생활 장소를 추천한다.
- 추천된 장소를 지도와 목록으로 직관적으로 확인할 수 있도록 한다.
- 외부 데이터 기반으로 실제 존재하는 장소 정보를 제공한다.
- 장소별 카테고리와 태그를 활용하여 추천 기준을 구성한다.
- 최신 확인일, 오류 제보, 검증 정보, 신뢰도 정보를 통해 추천 결과의 신뢰성을 높인다.
- 사용자가 장소 정보를 보완하고 검증할 수 있는 구조를 제공한다.
- 향후 AI를 활용하여 자연어 상황 검색, 태그 보강, 추천 이유 생성 기능으로 확장한다.

## 🧭 3. 서비스 한 줄 정의

## 🧩 4. 주요 기능

### 💡 4.1 상황 기반 장소 추천

사용자는 자신의 현재 상황이나 목적에 맞는 장소를 추천받을 수 있습니다.

예시:

- 화장실이 급할 때
- 주차할 곳이 필요할 때
- 흡연구역이 필요할 때
- 와이파이가 필요한 장소를 찾을 때
- 잠깐 쉴 곳이 필요할 때
- 조용한 카페가 필요할 때
- 산책하기 좋은 장소를 찾을 때
- 야경 보기 좋은 곳을 찾을 때
- 드라이브 목적지가 필요할 때

추천은 사용자의 위치, 선택한 상황, 장소 카테고리, 장소 태그, 최신 확인일, 신뢰도 정보를 기준으로 제공됩니다.

---

### 🏷️ 4.2 태그 기반 추천

장소에 등록된 태그를 기반으로 사용자의 조건에 맞는 장소를 추천합니다.

예시 태그:

- 조용함
- 와이파이
- 콘센트 있음
- 노트북 작업 가능
- 혼자 이용 좋음
- 야간 이용 가능
- 주차 가능
- 산책하기 좋음
- 야경 보기 좋음
- 잠깐 쉬기 좋음
- 최근 확인됨

## 태그 구분

| 구분 | 저장 여부 | 설명 | 예시 |
|---|---|---|---|
| 저장 태그 | DB 저장 | 검증되었거나 근거가 있는 장소 태그 | 흡연구역, 주차가능, 콘센트확인 |
| 임시 태그 | DB 저장 안 함 | 지도 API 검색 결과에 추천 시점에 붙이는 태그 | 카페, 실내후보, 산책후보, 야경후보 |
| 계산 값 | DB 저장 안 함 | 사용자 요청마다 달라지는 추천 계산 결과 | 거리, 가까움, 추천점수 |

- 가까운 무료 와이파이 장소 추천

- 주변 카페 후보 조회

AI는 실제 장소 정보를 임의로 생성하지 않고, 확보된 장소 데이터를 추천에 활용하기 쉽게 정리하는 보조 기능으로 사용합니다.

활용 예시:

- 사용자 자연어 입력을 카테고리와 태그 조건으로 변환

- 후기 또는 제보 내용 요약
- 관리자 검수 보조

예시:

사용자 입력:

"밤에 차 세우고 야경 볼 만한 곳 추천해줘"

AI 변환 결과:

- 카테고리: 공원, 전망지, 관광지, 주차장
- 태그: 야경, 주차 가능, 야간 이용 가능, 드라이브
- 정렬 기준: 거리, 태그 일치도, 신뢰도

## 🧮 5. 추천 방식

초기 추천은 복잡한 머신러닝 방식이 아니라 규칙 기반 추천 방식으로 구현합니다.

추천 점수는 다음 요소를 기준으로 계산합니다.

추천 점수 =
상황 일치 점수
+ 카테고리 일치 점수
+ 태그 일치 점수
+ 거리 점수
+ 최신 확인 점수
+ 신뢰도 점수
- 오류 제보 감점

초기에는 위치 기반, 상황 기반, 태그 기반 추천을 중심으로 구현하고, 이후 사용자 행동 데이터가 쌓이면 개인화 추천으로 확장합니다.

추천의 핵심은 단순 지도 API 검색 결과가 아니라, 장소별 추천 가치 태그와 태그의 신뢰도입니다. 지도 API 검색 결과는 장소 후보를 확보하는 보조 수단으로 사용하며, 자체 수집 데이터, 팀 확인 장소, 사용자 저장/검증 장소는 DB에 저장하여 태그의 출처와 상태를 관리합니다.

태그는 카테고리/필터용 태그, 추천 가치 태그, 상태/주의 태그로 구분합니다. 특히 혼자 이용 좋음, 오래 머물기 좋음, 조용함, 노트북 작업 가능, 콘센트 있음, 와이파이 있음 같은 추천 가치 태그는 후보 태그와 검증 태그를 분리하여 관리합니다.

## 실시간 장소 검색 기반 추천 구조

본 서비스는 모든 장소 데이터를 자체 DB에 저장한 뒤 추천하는 방식만 사용하지 않는다.

카페, 드라이브 목적지, 야경 후보, 근처 산책 장소처럼 자체 데이터 확보가 어려운 장소는 지도 API의 실시간 장소 검색 결과를 활용한다.

지도 API로 검색된 장소는 DB에 즉시 저장하지 않고, 추천 시점에 카테고리, 장소명, 검색 키워드, 사용자 상황을 기준으로 임시 태그를 부여한다.

임시 태그는 추천 점수 계산과 추천 이유 생성에 활용되며, 검증되지 않은 정보는 후보 정보로 표시한다.

자체 DB는 공공데이터 기반 장소, 팀이 직접 확인한 장소, 관리자 검증 장소, 사용자 저장 또는 제보로 관리가 필요한 장소를 저장하는 용도로 사용한다.

## 📊 7. 데이터 활용 방향

본 프로젝트의 데이터는 외부 데이터 기반 장소 정보와 서비스 내부에서 생성되는 보완 정보로 구성합니다.

### 📂 7.1 외부 데이터 기반 장소 정보

공공데이터 또는 사용 조건이 확인된 외부 데이터를 활용하여 실제 장소 정보를 제공합니다.

검토 대상:

- 공중화장실
- 주차장
- 흡연구역
- 무료 와이파이
- 도시공원
- 쉼터
- 관광지 및 명소
- 상권 기반 카페 후보 데이터

데이터 사용 여부는 다음 기준을 확인한 뒤 결정합니다.

- 데이터가 실제로 존재하는가
- 좌표 정보가 제공되는가
- 갱신일 또는 기준일이 있는가
- 프로젝트에서 사용 가능한 라이선스인가
- 서비스 핵심 기능에 활용 가능한가
- fixtures 형태로 가공 가능한가

---

### 🏷️ 7.2 추천 태그 데이터

외부 데이터에는 장소명, 주소, 좌표, 카테고리만 있고 추천에 필요한 세부 태그가 부족할 수 있습니다.

이를 보완하기 위해 다음 방식으로 태그를 구성합니다.

- 카테고리 기반 기본 태그 부여
- AI 기반 추천 태그 후보 생성
- 관리자 확인 태그
- 사용자 검증 기반 태그

AI가 생성한 태그는 확정 정보가 아니라 추천 후보로 구분하며, 신뢰도와 출처를 함께 저장합니다.

| 📍 장소 상세 페이지 | 선택한 장소의 상세 정보를 확인하는 화면 | 위치, 태그, 후기, 신뢰도, 최신 확인일 |
| 📝 장소 제보 페이지 | 사용자가 새로운 장소를 등록하는 화면 | 위치 선택, 카테고리 선택, 태그 선택, 설명 입력 |
| 🚨 장소 수정/오류 제보 페이지 | 잘못된 장소 정보를 수정 요청하는 화면 | 오류 유형 선택, 수정 내용 입력 |
| ⭐ 내 장소 페이지 | 사용자가 저장하거나 제보한 장소를 확인하는 화면 | 저장 목록, 제보 목록, 검증 내역 |
| 🛡️ 관리자 페이지 | 제보와 신고를 관리하는 화면 | 승인/반려, 신고 처리, 장소 수정, 태그 검수 |

## ⚠️ 13. 주의사항

- AI는 실제 장소 정보를 임의로 생성하지 않습니다.
- 추천 결과는 외부 데이터, 내부 장소 데이터, 태그, 신뢰도, 최신 확인일을 기반으로 제공합니다.
- 공공데이터 사용 여부는 데이터 제공 조건과 좌표 제공 여부를 확인한 뒤 확정합니다.
- 지도 API 검색 결과를 대량 저장하는 방식은 API 제공사의 정책 확인 후 결정합니다.
- 초기 구현에서는 완성 가능한 기능 범위를 우선합니다.
- 데이터 확보가 불확실한 기능은 핵심 기능으로 확정하지 않습니다.
