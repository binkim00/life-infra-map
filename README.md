# 🗺️ 지도 기반 생활 인프라 추천 서비스

## 📌 1. 프로젝트 소개

본 프로젝트는 사용자가 현재 위치 또는 특정 지역에서 필요한 생활 인프라를 빠르게 찾을 수 있도록 돕는 지도 기반 서비스입니다.

공중화장실, 주차장, 흡연구역, 쉬기 좋은 장소, 카페 등 생활 속에서 자주 필요한 장소 정보를 지도 위에서 확인할 수 있으며, 외부 데이터와 사용자 제보 데이터를 함께 활용하여 장소 정보를 보완하는 것을 목표로 합니다.

단순한 지도 검색 서비스가 아니라, 장소별 태그, 최근 확인 여부, 사용자 검증, 오류 제보, 신뢰도 정보를 활용하여 사용자의 상황에 맞는 장소를 추천하는 서비스입니다.

---

## 🎯 2. 서비스 목표

- 🗺️ 지도 기반으로 생활 인프라 장소를 조회할 수 있도록 한다.
- 📊 외부 데이터 기반 장소 정보를 제공한다.
- 📝 사용자가 직접 장소 정보를 제보하고 보완할 수 있도록 한다.
- 🏷️ 장소별 태그를 통해 상황에 맞는 장소를 찾을 수 있도록 한다.
- ✅ 최신 확인일, 검증, 오류 제보를 통해 장소 정보의 신뢰도를 높인다.
- 💡 태그 기반, 상황 기반, 사용자 행동 기반 추천으로 확장 가능한 구조를 설계한다.

---

## 🧩 3. 주요 기능

### 🗺️ 3.1 지도 기반 장소 조회

- 지도 화면에서 장소 마커 표시
- 현재 위치 또는 선택한 지역 기준 장소 조회
- 카테고리별 장소 필터링
- 장소 클릭 시 상세 정보 확인

### 📍 3.2 장소 상세 정보

- 장소명, 주소, 위치 정보
- 카테고리 및 태그
- 장소 설명
- 최신 확인일
- 신뢰도
- 후기 또는 메모
- 사용자 검증 정보

### 📝 3.3 사용자 제보

사용자는 새로운 장소를 제보하거나 기존 장소 정보를 보완할 수 있습니다.

- 신규 장소 제보
- 기존 장소 정보 수정 요청
- 장소 태그 제안
- 오류 제보
- 최신 확인 여부 등록

### ✅ 3.4 사용자 검증

장소 정보가 실제와 일치하는지 사용자가 검증할 수 있습니다.

- 정보가 맞아요
- 정보가 달라요
- 현재 이용 불가
- 오류 신고
- 사진 인증

### 💡 3.5 추천 기능

본 프로젝트는 **“추천”** 이라는 대주제에 맞춰 다음과 같은 추천 구조를 고려합니다.

#### 🏷️ 태그 기반 추천

장소에 등록된 태그를 기반으로 사용자 상황에 맞는 장소를 추천합니다.

예시:

- 조용한 장소 추천
- 노트북 작업 가능한 장소 추천
- 야간 이용 가능한 장소 추천
- 최근 확인된 장소 추천

#### 🧭 상황 기반 추천

사용자가 현재 상황을 선택하면 해당 상황에 적합한 장소를 추천합니다.

예시:

- 급하게 화장실이 필요할 때
- 잠깐 쉬고 싶을 때
- 노트북 작업할 곳이 필요할 때
- 주차 가능한 장소가 필요할 때

#### 👤 사용자 행동 기반 추천

사용자의 조회, 저장, 후기, 검증 행동을 기록하여 관심 있는 카테고리와 태그를 기반으로 추천합니다.

## 📊 5. 데이터 활용 방향

본 프로젝트의 데이터는 크게 두 가지 방식으로 구성합니다.

### 📂 5.1 외부 데이터 기반

공공데이터 또는 외부에서 확보 가능한 데이터를 활용하여 기본 장소 정보를 제공합니다.

검토 대상:

- 공중화장실
- 주차장
- 흡연구역

단, 실제 데이터 사용 여부는 다음 기준을 확인한 뒤 결정합니다.

- 데이터가 실제로 존재하는가
- 좌표 정보가 제공되는가
- 갱신일 또는 기준일이 있는가
- 프로젝트에서 사용 가능한 라이선스인가
- 서비스 핵심 기능에 활용 가능한가
- fixtures 형태로 가공 가능한가

### 🙋 5.2 사용자 제보 기반

외부 데이터만으로 확보하기 어려운 세부 정보는 사용자 제보를 통해 보완합니다.

예시:

- 카페 세부 정보
- 산책하기 좋은 곳
- 잠깐 쉬기 좋은 장소
- 혼자 쉬기 좋은 장소
- 생활 속 유용한 장소

사용자 제보 데이터는 관리자 검수, 사용자 검증, 오류 제보 기능과 함께 관리합니다.

## ⚠️ 11. 주의사항

- AI는 실제 장소 정보를 임의로 생성하지 않습니다.
- 장소 정보는 외부 데이터, 사용자 제보, 관리자 검수 결과를 기반으로 제공합니다.
- 공공데이터 사용 여부는 데이터 제공 조건과 좌표 제공 여부를 확인한 뒤 확정합니다.
- 초기 MVP에서는 완성 가능한 기능 범위를 우선합니다.
- 데이터 확보가 불확실한 기능은 핵심 기능으로 확정하지 않습니다.
