## 2일차

### 진행 요약

- 생활 인프라 데이터 후보를 조사했습니다.
- 공중화장실, 주차장, 흡연구역, 쉼터, 공원, 공공와이파이 데이터를 수집 후보로 정리했습니다.
- 공공데이터 API, CSV, 지자체별 데이터 제공 현황을 확인했습니다.
- 흡연구역 데이터 확보를 위해 관련 지도 서비스의 데이터 로딩 구조를 분석했습니다.
- 흡연구역 데이터 632건을 수집하고 raw/normalized JSON 파일로 저장했습니다.
- 수집한 데이터는 최종적으로 공통 Place 구조로 정규화하기로 했습니다.

### 다음 작업

- 공중화장실, 주차장 데이터 수집
- 쉼터, 공원, 공공와이파이 데이터 조사
- 전체 수집 데이터 정리 및 공통 필드 확정
- Django Place 모델 설계
- fixtures 변환 준비
