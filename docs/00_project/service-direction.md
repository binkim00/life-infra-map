# 통합 서비스 방향 정리

기존 기획은 유지하고, 팀원 제안은 자연어 검색과 후기 기반 추정 태그를 보강하는 확장안으로 반영한다.

서비스 핵심은 여러 출처의 장소 데이터를 카테고리와 태그로 분류하고, 사용자의 자연어 입력 또는 빠른 선택 조건을 추천 조건으로 변환해 지도와 목록에 표시하는 것이다.

## 유지할 방향

- 실제 확보 가능한 장소 데이터를 우선 사용한다.
- 장소별 카테고리와 기본 태그를 저장한다.
- 추천은 카테고리, 태그, 거리, 최신성, 신뢰도 등을 기준으로 규칙 기반 점수를 계산한다.
- 지도는 추천 결과를 확인하는 핵심 화면으로 사용한다.

## 보강할 방향

- 자연어 검색창
- 빠른 지도 탭
- 블로그 검색 결과 기반 추가 태그 후보
- 후기 기반 추정 태그 표시
- 태그 근거 링크 제공
- AI/GMS를 자연어 입력에서 추천 조건으로 변환하는 데 활용

## 최종 흐름

```text
기본 장소 확보
→ 카테고리와 태그 부여
→ 추가 태그 후보 생성
→ 자연어 입력을 태그 조건으로 변환
→ 규칙 기반 추천 점수 계산
→ 지도와 목록에 표시
```
