# 프로젝트 진행 방향

## 0. 서비스 방향 기준 정리

1. 서비스 방향 통합 정리

- 기존의 “상황 기반 생활 장소 추천 지도 서비스” 방향을 유지한다.
- 팀원 정리안은 기존 기획을 대체하는 것이 아니라, 자연어 검색과 후기 기반 추정 태그를 보강하는 확장안으로 흡수한다.
- 서비스의 핵심은 기존 지도 서비스처럼 장소명을 단순 검색하는 것이 아니라, 여러 출처의 장소 데이터를 카테고리와 태그로 분류하고 사용자의 상황에 맞게 추천하는 것이다.
- 지도는 추천 결과와 장소 정보를 확인하는 핵심 인터페이스로 사용한다.

2. 데이터 활용 기준 정리

- 공공데이터, CSV, API, 팀 시드 데이터를 중심으로 실제 확보 가능한 장소 데이터를 우선 사용한다.
- 지도 API는 장소 후보 조회, 좌표/주소 확인, 추천 결과 부족 시 외부 후보 표시 등 보조 수단으로 활용한다.
- 블로그 검색 결과는 본문 전체 분석이 아니라 제목, 요약, 작성일, URL 기반의 추가 태그 후보 생성에 활용한다.
- 블로그 기반 태그는 확정 정보가 아니라 “후기 기반 추정 태그”로 구분한다.

3. 추천 구조 기준 정리

- 사용자의 자연어 입력 또는 빠른 선택 조건을 카테고리/태그 조건으로 변환한다.
- 추천은 카테고리 일치, 태그 일치, 거리, 최신성, 신뢰도, 오류 제보 감점 등을 조합한 규칙 기반 점수로 처리한다.
- AI는 실제 장소 정보를 임의 생성하지 않고, 자연어 입력을 추천 조건으로 변환하거나 추천 이유를 생성하는 보조 역할로 사용한다.
