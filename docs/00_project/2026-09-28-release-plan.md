## 현재 상태

- 로컬: Django 전체 890개 검사 통과(21건 건너뜀), Spring 전체 테스트 통과, 웹 78개 검사·빌드 통과, 모바일 타입·린트·웹 내보내기 통과, Android Release APK 생성. 신규 Codex 검토·되돌리기 검사는 별도로 통과했다.
- 운영: 7개 컨테이너 정상, 루트 디스크 29GB 중 83% 사용·약 5.0GB 여유. Django migration은 accounts 0004, boards 0009, recommendations 0028까지 적용됐다. 2026-09-28 02:34 UTC 정기 DB 백업이 S3에 업로드됐다(461,298,575바이트, 성공 기록).
- 배포 대상 기존 코드와 로컬 기준 파일을 해시 비교했다. 서버 고유 차이는 테스트 파일 2개뿐이어서 그 파일은 보존하고 필요한 코드만 선별 반영한다. 서버 Git 상태에는 줄바꿈 등으로 수백 건이 표시되므로 전체 디렉터리를 덮어쓰지 않는다.
- 새 기능·migration·타이머는 아직 운영에 반영되지 않았다. Google OAuth는 테스트 사용자 1명, 네이버 앱은 개발 중 상태다. 실제 공급자 로그인 왕복은 미검증이다.

## 반영 순서

1. 현재 운영 상태와 디스크 여유, 새 백업의 성공·복원 가능성을 확인한다. 배포 대상 파일의 원본을 별도 보관하고 내용 해시를 남긴다.
2. 서버 고유 테스트 파일과 `.env`·SSH 키·runtime 데이터는 건드리지 않고, Django/Spring/웹/배포 설정의 변경 파일만 반영한다. 소셜 비밀값은 코드·채팅·문서에 넣지 않는다.
3. Django accounts 0005~0007, boards 0010을 먼저 적용한다. recommendations 0029는 실제 SQL의 `UPPER(column::text)`와 일치하는 GIN trigram 인덱스를 `CONCURRENTLY` 생성하므로 디스크 사용량을 확인하며 적용한다. 90% 사용 또는 여유 2GiB 이하로 가면 다음 단계 전에 중단·검토한다.
4. Django, Spring, 게이트웨이/웹을 하나씩 빌드·재시작하고 헬스, 기존 로그인·갱신·로그아웃, 관리자 문의·근거 화면, 일반/선택 검색을 점검한다. `스타벅스 서면`의 첫 요청·반복 요청·DB 구간을 배포 전 측정과 비교한다.
5. 사용자 본인이 개인 보관함의 3사 클라이언트 ID/비밀값을 서버 대화형 입력 도구로 넣은 후에만 소셜 로그인을 켠다. Google 테스트 계정의 웹·앱 왕복, 검증 이메일 연결, 신규 계정, 취소, 티켓 재사용·만료를 확인한다. Google 게시 상태와 네이버 심사 상태를 확인하기 전에는 공개 이용자 로그인 완료로 표시하지 않는다.
6. Codex 2차 검토는 영속 백업 폴더를 먼저 준비하고 미반영 preview로 첫 배치를 확인한다. 그 결과가 안전하면 하루 최대 5건 타이머를 설치·켜고 첫 적용의 백업·승인 상태·집계·중복·실패 알림을 확인한다.
7. Android APK를 실제 기기에 설치해 로그인 유지, 소셜 로그인, 필터 검색, 문의, 관리자 화면을 직접 점검한다. 기기가 없으면 기기 검증은 별도 미완료로 남긴다.

## 되돌리기

- 배포한 코드와 Compose 설정은 사전에 보관한 파일만 선별 복원한다. DB migration은 적용 이력과 데이터 보존을 우선하므로 무조건 되돌리지 않는다. 필요하면 S3 백업·복원 검증 절차를 사용한다.
- Codex 자동 검토의 특정 배치는 `backup-*.json`으로 `rollback_codex_content_review` 미리보기를 거쳐 되돌린다. 사람이 이후 변경한 근거는 자동 되돌리기가 중단한다.
- 소셜 로그인 문제가 생기면 `SOCIAL_LOGIN_ENABLED=false`로 신규 소셜 시작을 막고 기존 일반 로그인·갱신 흐름을 확인한다.

## 운영 반영 전 게이트

운영 배포는 프로젝트 `AGENTS.md`의 별도 요청 요건에 따라 사용자 승인을 받은 뒤 진행한다. 소셜 비밀값 입력은 사용자가 직접 한다. 디스크 여유, 최신 백업, 서버 고유 변경 보존, 3사 공개 상태와 실제 로그인 왕복 확인 전에는 전체 완료로 보고하지 않는다.
