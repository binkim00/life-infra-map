# 여기일지도 스토어 게시 전 확인 목록

2026-09-29 기준. `완료`는 적힌 범위에서만 검증됐다는 뜻이다. `확인 필요`는 코드 검색이나 이전 기록만으로 운영 결과를 단정할 수 없는 항목이다. 앱 출시 승인을 뜻하지 않는다.

## 1. 현재 판단

**Android와 iOS 모두 공개 게시 준비 전이다.** 웹 HTTPS와 API 상태, CI 검사, 테스트 Android APK의 이름·아이콘은 확인했다. 출시 앱의 공개 주소, 스토어용 빌드, 스토어 계정·정책 입력, 전체 실기기 흐름은 아직 검증되지 않았다. 웹을 앱 소개 페이지로 바꾸는 일과 CD 완전 자동화는 스토어 심사의 선행 조건이 아니다. 단, 공개 개인정보처리방침·계정 삭제 요청·고객 지원 주소는 필요하다.

## 5. 서비스 기능 검증 — 출시용 빌드에서 다시 확인

기존 자동 검사는 코드 회귀 검사이고, 운영 API 표본이나 테스트 APK 실기기 검사는 **스토어에 올릴 빌드의 전체 기능 합격**과 다르다. 아래 `기존 확인`은 2026-09-29까지의 제한된 증거다. `필수`는 현재 서비스에서 제공하는 핵심 흐름의 출시 판단 기준이며 스토어의 공식 심사 항목이라는 뜻은 아니다. 각 행을 출시용 Android AAB의 Play 내부 테스트 설치본과 추후 iOS TestFlight 설치본에서 다시 확인한다. 기능별 정상·빈 결과·실패·권한 거부를 기록하고, 실패 시 원인과 수정 후 재시험 결과를 남긴다.

| 조건부 | 공개 웹 기능 | 웹을 계속 제공하는 동안 같은 도메인에서 로그인·검색·지도·상세·문의가 동작하고 모바일과 결과 기준이 일치한다. 앱 소개 페이지로 전환하면 남기는 공개 정책/지원/삭제 요청 경로와 서버 API를 재검증한다. | 웹 HTML·화면 자산·API 상태 응답은 확인했다. 브라우저에서의 전체 사용 흐름과 새 주소의 웹 소셜 로그인은 미검증이다. |
| 권장 | 기기·접근성·성능 | 작은/큰 화면, 글자 크기 확대, 스크린리더 라벨, 색 대비, Android 여러 버전과 iPhone, 긴 목록 스크롤·메모리, 앱 시작/검색 대기 시간을 확인한다. | 포괄적 기기 매트릭스와 접근성 검증 기록은 없다. |

**운영 확인:** 공개 HTTPS, API 권한, 백업 복원, 경보, 서버 용량 90% 기준, 실패 배포 복구와 문의/신고 처리 담당·응답 절차도 출시 판단에 포함한다. 기존 자동 승인·검색 평가는 품질 신호이며, 평가 수치만으로 실제 사용자 흐름을 통과한 것으로 취급하지 않는다.

## 6. 스토어 설명과 게시 순서

1. 공개 주소·인증·계정 삭제·UGC 정책의 차단 항목을 해결하고, 출시 빌드로 위 이용 흐름을 검증한다.
2. 실제 기능만 설명하는 앱 이름, 아이콘, 설명, 스크린샷, 권한 설명, 고객 지원·개인정보처리방침·삭제 주소를 준비한다. 웹 첫 화면을 앱 소개로 바꾸는 것은 선택 사항이다.
3. Android AAB → Play 내부 테스트 → 해당되면 12명/14일 비공개 테스트 → 공개 배포 접근 신청·심사 순으로 간다. iOS는 계정·로그인 요건 확정 → IPA → TestFlight → App Store 심사 순으로 간다.
4. 공개 후 오류율·로그인·검색 품질·문의/신고 대응·디스크/백업을 모니터링한다. CD 완전 자동화는 출시 필수 조건은 아니지만 수동 배포의 백업·검증·복구 절차는 필요하다.
