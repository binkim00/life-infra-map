# 지도 API 테스트 기록

## 테스트 결과

- 카카오 REST API를 통해 키워드 기반 장소 검색에 성공했다.
- 카카오 JavaScript SDK를 통해 프론트 화면에 지도를 표시했다.
- 브라우저 현재 위치를 기준으로 추천 API에 lat/lng를 전달했다.
- 추천 결과의 좌표를 지도 마커로 표시했다.
- 카페, 공원 검색은 결과가 정상적으로 반환되었다.
- 흡연구역은 카카오 키워드 검색만으로 결과가 부족하여 별도 공공데이터 또는 수집 데이터 활용이 필요하다.

## 판단

카페, 산책/힐링 장소처럼 지도 API 검색 결과를 활용할 수 있는 시나리오는 실시간 검색 기반 추천 구조로 구현 가능하다.

흡연구역처럼 지도 API 검색 결과가 부족한 시나리오는 자체 수집 데이터 또는 공공데이터를 DB에 저장한 뒤 추천에 함께 활용하는 혼합형 구조가 필요하다.
