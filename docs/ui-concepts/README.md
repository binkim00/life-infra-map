# LifeMap 모바일 UI 콘셉트 보드

이 폴더의 이미지는 2026-09-15 기준 모바일 라우트와 기능을 빠짐없이 재배치하기 위한 시각 시안이다. 이미지 속 작은 문구는 이미지 생성 과정에서 일부 변형될 수 있으므로 실제 구현 문구와 기능 범위는 `docs/UI_REDESIGN_COVERAGE.md`를 기준으로 한다.

## 보드

1. `01-discovery-search-detail.png`: 홈, 일반 지도 검색, 장소 상세
2. `02-recommend-saved-report.png`: 상황 추천, 장소 그룹·메모, 지도 핀 장소 제보
3. `03-admin-dashboard-evidence-report.png`: 운영 대시보드, 근거 검토, 장소 제보 승인
4. `04-auth-mypage-preferences.png`: 로그인, 회원가입, 마이페이지, 선호·알림 설정
5. `05-history-report-receipt.png`: 검색 기록, 내 제보 목록, 제보 영수증 상세
6. `06-community-notifications-inquiries.png`: 게시판 목록·상세·작성/수정, 알림, 내 문의·문의 작성
7. `07-admin-users-moderation.png`: 관리자 메뉴, 회원 목록·상세, 커뮤니티 신고·문의 관리
8. `08-audits-guides-states.png`: 수집 판정 기록, 근거 상세 판정, 이용가이드, 승급가이드, 공통 로딩·빈 상태·오류

## 공통 생성 방향

- 용도: 고해상도 모바일 UI 콘셉트 보드
- 인상: 깔끔하고 익숙한 국내 대중 서비스 수준의 지도·커뮤니티 UX
- 색상: 잉크 `#17201D`, 청록 `#0F857A`, 연민트 `#E9F5F2`, 웜화이트 `#FAFBF9`, 회색 `#EEF1EF`, 강조 코랄 `#FF765E`
- 지도 검색: 검색 결과 위치 이동, 번호 핀, 현재 지도 재검색, 현재 위치, 지도·목록 연동
- 추천: 충족 근거와 확인 필요 조건을 분리
- 관리자: 처리할 일을 먼저 보여주고 원시 JSON과 모바일용 데스크톱 표를 피함
- 상태: 로딩, 빈 상태, 오류, 재시도, 진행 중, 성공/실패를 명확히 구분
- 제한: 그라데이션·글래스모피즘·워터마크·과도한 영문·과도한 칩 사용 금지

이미지는 기본 내장 이미지 생성 도구로 만들었다.
