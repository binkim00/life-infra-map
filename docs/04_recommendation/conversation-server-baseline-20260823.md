# 대화 검색 서버 DB 기준선 (2026-08-23)

## 검증 조건

- 30개 대화, 59개 발화 단계
- 서버 PostgreSQL 사용
- `PGOPTIONS=-c default_transaction_read_only=on`
- 외부 AI, 웹 검색, Kakao 검색 비활성화
- 평가 원본은 서버 임시 경로에만 보관하고 집계값만 반출

대화 문맥, 후속 조건 누적, 이전 결과 비교·선택·초기화가 적용되면서 정상
판정은 12개에서 35개로 증가했다. 검색으로 정상 진입하는 발화가 늘면서
결과 없음도 13개에서 23개로 증가했으므로, 다음 병목은 파서보다 서버 DB의
지역·조건별 태그 근거 커버리지다.

결과가 0~2개인 검색은 사용자 원문을 저장하지 않고 정규화된 지역,
카테고리, 주관 태그만 수요 신호로 기록한다. 일일 태그 수집 계획은 이 신호를
후보 점수와 대상 태그에 반영한다.
