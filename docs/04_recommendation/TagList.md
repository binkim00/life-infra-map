# 표준 태그 목록

## 1. 문서 목적

본 문서는 상황 기반 생활 장소 추천 지도 서비스에서 사용할 표준 태그 목록을 정리합니다.

태그는 단순 표시용이 아니라 추천 조건, 필터, 추천 이유, 신뢰도 판단에 함께 사용됩니다.

현재 태그는 아래 기준으로 관리합니다.

- 카테고리 기반 기본 태그
- 원본 컬럼 기반 확정 가능 태그
- 블로그/키워드 기반 후보 태그
- AI 또는 규칙 기반 후보 태그
- 검수 또는 사용자 검증을 거친 태그

---

## 2. 생활 불편 해결 태그

공공데이터 기반 장소와 직접 연결하기 좋은 태그입니다.

| 태그 | 설명 | 우선순위 | 상태 기준 |
|---|---|---|---|
| 화장실 | 공중화장실이 필요한 상황 | Must | 카테고리 기반 확정 가능 |
| 주차 가능 | 주차장이 필요하거나 차량 이용 시 필요 | Must | 주차장 카테고리 또는 원본 컬럼 기반 |
| 흡연 가능 | 흡연구역 또는 흡연 가능 장소 | Must | 흡연구역 카테고리 기반 |
| 무료 와이파이 | 공공 와이파이 또는 와이파이 이용 가능 장소 | Must | 무료 와이파이 데이터 기반 |
| 잠깐 쉬기 좋음 | 쉼터, 공원, 카페 등 잠시 머물 수 있는 장소 | Must | 카테고리/후보 태그 구분 필요 |
| 무료 이용 | 비용 없이 이용 가능한 장소 | Should | 요금 컬럼이 있을 때 확정 가능 |
| 접근성 좋음 | 위치 접근이 쉬운 장소 | Should | 거리/위치 기반 계산값 |

---

## 3. 카페/실내 장소 추천 태그

카페 추천에서 중요한 태그입니다. 다만 일부는 실제 확인 근거가 부족할 수 있으므로 후보 태그와 확정 태그를 구분합니다.

| 태그 | 설명 | 우선순위 | 상태 기준 |
|---|---|---|---|
| 분위기 좋음 | 인테리어, 감성, 전체 분위기가 좋은 장소 | Must | 블로그/키워드 기반 후보 |
| 대화하기 좋음 | 친구, 지인과 대화하기 좋은 장소 | Must | 블로그/키워드 기반 후보 |
| 혼자 이용 좋음 | 혼자 방문하거나 혼자 머물기 좋은 장소 | Must | 블로그/키워드 기반 후보 |
| 쾌적함 | 청결, 공간 여유, 관리 상태가 좋은 장소 | Must | 후보 또는 검증 필요 |
| 사진 찍기 좋음 | 사진이 잘 나오거나 인테리어가 좋은 장소 | Should | 블로그/키워드 기반 후보 |
| 오래 머물기 좋음 | 좌석, 공간, 분위기상 오래 있기 좋은 장소 | Should | 후보 또는 검증 필요 |
| 데이트/모임 적합 | 데이트, 약속, 모임 장소로 적합한 곳 | Should | 후보 태그 |
| 친절함 | 응대나 서비스가 좋다고 평가되는 장소 | Could | 후기 기반 후보 |

---

## 4. 작업/공부 관련 태그

노트북 작업이나 공부 장소 추천에 필요한 태그입니다.

이 태그들은 실제 근거가 필요한 경우가 많으므로, 초기에는 후보 태그로 관리하고 검수 후 확정 태그로 전환합니다.

| 태그 | 설명 | 우선순위 | 상태 기준 |
|---|---|---|---|
| 조용함 | 조용하거나 집중하기 좋은 장소 | Should | 블로그/키워드 기반 후보 또는 직접 확인 |
| 노트북 작업 가능 | 노트북 작업에 적합한 장소 | Should | 조합 태그, 검증 필요 |
| 콘센트 있음 | 전원 사용이 가능한 장소 | Should | 직접 확인 또는 명확한 근거 필요 |
| 와이파이 있음 | 인터넷 이용이 가능한 장소 | Should | 직접 확인 또는 원본 데이터 필요 |
| 좌석 편함 | 좌석이 편하거나 머물기 좋은 장소 | Could | 후보 또는 검증 필요 |
| 공부하기 좋음 | 공부나 집중 목적에 적합한 장소 | Could | 후보 또는 검증 필요 |

`노트북 작업 가능`은 단독 확정 태그라기보다 아래 조건을 종합해 판단하는 조합 태그입니다.

```txt
노트북 작업 가능 후보 =
  와이파이 있음
+ 콘센트 있음
+ 조용함
+ 오래 머물기 좋음
```

## 5. 산책/힐링 장소 태그

공원, 쉼터, 관광지, 해수욕장 데이터와 연결하기 좋은 태그입니다.

| 태그 | 설명 | 우선순위 | 상태 기준 |
|---|---|---|---|
| 산책하기 좋음 | 산책로, 공원, 강변 등 걷기 좋은 장소 | Must | 공원/관광지 기반 후보 또는 확정 |
| 힐링하기 좋음 | 쉬거나 기분 전환하기 좋은 장소 | Must | 후보 태그 |
| 자연/녹지 | 공원, 숲, 강변 등 자연 요소가 있는 장소 | Should | 카테고리/원본 분류 기반 |
| 전망 좋음 | 시야가 트이거나 경관이 좋은 장소 | Should | 관광지/블로그 기반 후보 |
| 야경 보기 좋음 | 야경 감상에 적합한 장소 | Should | 후보 태그, 검증 필요 |
| 조용히 쉬기 좋음 | 한적하거나 조용히 머물기 좋은 장소 | Should | 후보 태그, 검증 필요 |
| 가족과 가기 좋음 | 가족 단위 방문에 적합한 장소 | Could | 후보 태그 |

---

## 6. 드라이브/이동 관련 태그

드라이브 코스 추천은 고도화 기능으로 두고, 초기에는 드라이브 목적지 후보 태그로 관리합니다.

| 태그 | 설명 | 우선순위 | 상태 기준 |
|---|---|---|---|
| 드라이브 목적지 | 차량으로 방문하기 좋은 장소 | Should | 관광지/해수욕장/전망 장소 후보 |
| 주차 연계 가능 | 주변 주차장과 함께 추천 가능한 장소 | Should | 주차장 데이터 연계 필요 |
| 야간 방문 가능 | 밤에도 방문 후보가 될 수 있는 장소 | Could | 운영시간 또는 검증 필요 |
| 경치 좋음 | 드라이브나 나들이 목적지로 적합한 경관 | Could | 후보 태그 |
| 근교 나들이 | 가볍게 이동해서 방문하기 좋은 장소 | Could | 후보 태그 |

## 7. 시간/상태 관련 태그

추천 점수와 사용자 안내에 반영하기 좋은 태그입니다.

| 태그 | 설명 | 우선순위 | 상태 기준 |
|---|---|---|---|
| 최근 확인됨 | 최근 확인일이 있는 장소 | Must | 확인일 기준 |
| 운영 정보 확인 필요 | 운영 여부가 불확실한 장소 | Should | 정보 부족 또는 후보 태그 |
| 야간 이용 가능 | 밤에도 이용 가능한 장소 | Should | 운영시간 근거 필요 |
| 오류 제보 있음 | 정보 불일치 또는 문제 제보가 있는 장소 | Should | 사용자/관리자 제보 기반 |
| 관리자 확인됨 | 관리자가 확인한 장소 | Could | 관리자 검수 기반 |
| 후보 태그 검수 필요 | 블로그/AI/키워드 기반 후보 태그 | Should | candidate 상태 |

## 9. 태그 우선순위

### Must

서비스 핵심 추천에 바로 필요한 태그입니다.

```txt
화장실
주차 가능
흡연 가능
무료 와이파이
잠깐 쉬기 좋음
분위기 좋음
대화하기 좋음
혼자 이용 좋음
쾌적함
산책하기 좋음
힐링하기 좋음
```

### Should

추천 품질을 올려주는 태그입니다.

```txt
사진 찍기 좋음
오래 머물기 좋음
조용함
노트북 작업 가능
콘센트 있음
와이파이 있음
자연/녹지
전망 좋음
야경 보기 좋음
드라이브 목적지
최근 확인됨
운영 정보 확인 필요
후보 태그 검수 필요
```

### Could

고도화 또는 데이터가 충분할 때 쓰면 좋은 태그입니다.

```txt
좌석 편함
공부하기 좋음
데이트/모임 적합
친절함
가족과 가기 좋음
야간 방문 가능
주차 연계 가능
경치 좋음
근교 나들이
관리자 확인됨
```

## 10. 태그 출처 구분

| 출처 | 설명 |
|---|---|
| category_rule | 카테고리 기반 자동 태그 |
| field_rule | 원본 컬럼 기반 태그 |
| keyword_rule | 장소명/설명 키워드 기반 추론 태그 |
| blog_search | 블로그 검색 결과 기반 후보 태그 |
| ai_suggested | AI가 추천한 후보 태그 |
| external_data | 외부 데이터에서 직접 확인 가능한 태그 |
| team_checked | 팀이 직접 확인한 태그 |
| admin_checked | 관리자 또는 팀 검수 태그 |
| user_verified | 사용자 검증 기반 태그 |

---

## 11. 태그 상태 구분

| 상태 | 설명 |
|---|---|
| confirmed | 데이터에서 직접 확인 가능하거나 검수 완료된 태그 |
| candidate | 가능성은 있지만 근거가 약한 후보 태그 |
| needs_verification | 검증이 필요한 태그 |
| rejected | 검증 결과 맞지 않는 태그 |

---

## 12. 주의 사항

- 블로그 검색 결과 기반 태그는 확정 정보가 아니라 후보 태그입니다.
- AI가 제안한 태그도 확정 태그가 아니라 후보 태그입니다.
- 공공데이터 컬럼으로 확인할 수 없는 시설 정보는 확정하지 않습니다.
- `조용함`, `콘센트 있음`, `노트북 작업 가능`, `야경 보기 좋음`은 검증 전까지 약하게 반영합니다.
- 추천 카드에는 후보 태그와 확정 태그를 구분해 보여주는 방향을 고려합니다.
