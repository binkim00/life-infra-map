# 표준 태그 목록 초안

## 1. 생활 불편 해결 태그

공공데이터 기반 장소와 직접 연결하기 좋은 태그
| 태그       | 설명                         | 우선순위   |
| -------- | -------------------------- | ------ |
| 화장실      | 공중화장실이 필요한 상황              | Must   |
| 주차 가능    | 주차장이 필요하거나 차량 이용 시 필요      | Must   |
| 흡연 가능    | 흡연구역 또는 흡연 가능 장소           | Must   |
| 무료 와이파이  | 공공 와이파이 또는 와이파이 이용 가능 장소   | Must   |
| 잠깐 쉬기 좋음 | 쉼터, 공원, 카페 등 잠시 머물 수 있는 장소 | Must   |
| 무료 이용    | 비용 없이 이용 가능한 장소            | Should |
| 접근성 좋음   | 위치 접근이 쉬운 장소               | Should |

---

## 2. 카페/실내 장소 추천 태그

카페 추천에서 가장 중요한 태그

| 태그        | 설명                       | 우선순위   |
| --------- | ------------------------ | ------ |
| 분위기 좋음    | 인테리어, 감성, 전체 분위기가 좋은 장소  | Must   |
| 대화하기 좋음   | 친구, 지인과 대화하기 좋은 장소       | Must   |
| 혼자 이용 좋음  | 혼자 방문하거나 혼자 머물기 좋은 장소    | Must   |
| 쾌적함       | 청결, 공간 여유, 관리 상태가 좋은 장소  | Must   |
| 사진 찍기 좋음  | 사진이 잘 나오거나 인테리어가 좋은 장소   | Should |
| 오래 머물기 좋음 | 좌석, 공간, 분위기상 오래 있기 좋은 장소 | Should |
| 데이트/모임 적합 | 데이트, 약속, 모임 장소로 적합한 곳    | Should |
| 친절함       | 응대나 서비스가 좋다고 평가되는 장소     | Could  |

---

## 3. 작업/공부 관련 태그

노트북 작업이나 공부 장소 추천에 필요한 태그
다만 직접 근거가 있어야 하는 태그가 많아서, 일부는 후보 태그로 관리

| 태그        | 설명                 | 우선순위   |
| --------- | ------------------ | ------ |
| 조용함       | 조용하거나 집중하기 좋은 장소   | Should |
| 노트북 작업 가능 | 노트북 작업에 적합한 장소     | Should |
| 콘센트 있음    | 전원 사용이 가능한 장소      | Should |
| 와이파이 있음   | 인터넷 이용이 가능한 장소     | Should |
| 좌석 편함     | 좌석이 편하거나 머물기 좋은 장소 | Could  |
| 공부하기 좋음   | 공부나 집중 목적에 적합한 장소  | Could  |

주의할 점은 `노트북 작업 가능`은 단독 태그라기보다 조합 태그

```text
노트북 작업 가능 후보 =
와이파이 있음
+ 콘센트 있음
+ 조용함
+ 오래 머물기 좋음
```

---

## 4. 산책/힐링 장소 태그

공원, 쉼터, 관광/명소 데이터와 연결하기 좋은 태그

| 태그        | 설명                       | 우선순위   |
| --------- | ------------------------ | ------ |
| 산책하기 좋음   | 산책로, 공원, 강변 등 걷기 좋은 장소   | Must   |
| 힐링하기 좋음   | 쉬거나 기분 전환하기 좋은 장소        | Must   |
| 자연/녹지     | 공원, 숲, 강변 등 자연 요소가 있는 장소 | Should |
| 전망 좋음     | 시야가 트이거나 경관이 좋은 장소       | Should |
| 야경 보기 좋음  | 야경 감상에 적합한 장소            | Should |
| 조용히 쉬기 좋음 | 한적하거나 조용히 머물기 좋은 장소      | Should |
| 가족과 가기 좋음 | 가족 단위 방문에 적합한 장소         | Could  |

---

## 5. 드라이브/이동 관련 태그

드라이브 코스까지는 나중 기능으로 두더라도, **드라이브 목적지 추천**

| 태그       | 설명                    | 우선순위   |
| -------- | --------------------- | ------ |
| 드라이브 목적지 | 차량으로 방문하기 좋은 장소       | Should |
| 주차 연계 가능 | 주변 주차장과 함께 추천 가능한 장소  | Should |
| 야간 방문 가능 | 밤에도 방문 후보가 될 수 있는 장소  | Could  |
| 경치 좋음    | 드라이브나 나들이 목적지로 적합한 경관 | Could  |
| 근교 나들이   | 가볍게 이동해서 방문하기 좋은 장소   | Could  |

---

## 6. 시간/상태 관련 태그

추천 점수에 반영하기 좋은 태그

| 태그          | 설명                     | 우선순위   |
| ----------- | ---------------------- | ------ |
| 최근 확인됨      | 최근 확인일이 있는 장소          | Must   |
| 운영 정보 확인 필요 | 운영 여부가 불확실한 장소         | Should |
| 야간 이용 가능    | 밤에도 이용 가능한 장소          | Should |
| 오류 제보 있음    | 정보 불일치 또는 문제 제보가 있는 장소 | Should |
| 관리자 확인됨     | 관리자가 확인한 장소            | Could  |

# 1차 태그 우선순위

## Must

서비스 핵심 추천에 바로 필요한 태그
```text
화장실
주차 가능
흡연 가능
무료 와이파이
잠깐 쉬기 좋음
분위기 좋음
대화하기 좋음
혼자 이용 좋음
쾌적함
산책하기 좋음
힐링하기 좋음
```

## Should

추천 품질을 올려주는 태그

```text
사진 찍기 좋음
오래 머물기 좋음
조용함
노트북 작업 가능
콘센트 있음
와이파이 있음
전망 좋음
야경 보기 좋음
드라이브 목적지
최근 확인됨
```

## Could

고도화 또는 데이터가 충분할 때 쓰면 좋은 태그

```text
좌석 편함
공부하기 좋음
데이트/모임 적합
친절함
가족과 가기 좋음
야간 방문 가능
주차 연계 가능
경치 좋음
관리자 확인됨
```

# 태그 출처 구분

| 출처             | 설명                    |
| -------------- | --------------------- |
| category_rule  | 카테고리 기반 자동 태그         |
| keyword_review | 방문자 리뷰 키워드 기반 태그      |
| ai_suggested   | AI가 추천한 후보 태그         |
| external_data  | 외부 데이터에서 직접 확인 가능한 태그 |
| admin_checked  | 관리자 또는 팀 검수 태그        |
| user_verified  | 사용자 검증 기반 태그          |

---

# 태그 상태 구분


| 상태                 | 설명                    |
| ------------------ | --------------------- |
| confirmed          | 데이터에서 직접 확인 가능한 태그    |
| inferred           | 키워드나 설명을 기반으로 추론한 태그  |
| candidate          | 가능성은 있지만 근거가 약한 후보 태그 |
| needs_verification | 검증이 필요한 태그            |
