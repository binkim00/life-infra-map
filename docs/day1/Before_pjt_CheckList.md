## 타당성 평가
- 실제로 구현이 가능한가?, 현재 우리의 시점에서?, [ex) 사용 가능 데이터, 기술 구현 가능 레벨 등]
- 데이터 타당성, 기술적 타당성, 경제적 타당성
- 필수 기능과 추가 기능, 예비 기능 등 우선 순위 매기기(MoSCoW)

## 고려사항
- 타겟이 누구인가? 누구의 어떤 불편을 해결할지
- 팀의 시스템 그림. 장고 뷰 디비의 연결 모습
- 팀의 핵심 API 명세 3개
- 팀의 그라운드룰 체크리스트

## 구현 기능 예시
1. 알림
2. 검색/필터/정렬
3. 기록/히스토리
4. 통계/리포트
5. AI 요약/추천/첨삭
