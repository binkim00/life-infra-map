## 2026-09-30 앱 후속 수정·가입 검증

- 공개 Spring API에서 별도 일반 계정의 JSON 가입 HTTP 201과 즉시 로그인 HTTP 200을 확인했다. 앱은 사진이 없는 가입을 JSON으로 보내도록 바꿨다. 계정 비밀번호와 토큰은 출력하거나 저장하지 않았다.
- 동일 소스의 Android 릴리스 APK를 arm64-v8a와 x86_64로 빌드했다. 연결 휴대폰의 테스트판에 `adb install -r`이 성공해 기존 관리자 로그인 데이터를 지웠거나 앱을 제거하지 않았다. 휴대폰 화면은 접힌 화면/잠금 상태여서 새 빌드의 개별 UI를 직접 읽지 못했다.
- 기존 `lifemap_pixel8_api36` 에뮬레이터의 동일 패키지가 다른 서명이라 덮어쓰지 않았다. 별도 `ddubi_pixel_8_api36` 에뮬레이터에 설치해 비로그인 홈에서 `생활 장소 추천`과 하단 홈·검색·추천·MY만 확인했다. 위치 권한 거부 상태에서도 홈이 열렸다. MY→로그인→Android 뒤로 가기는 홈 복귀, 홈의 첫 뒤로 가기는 종료 안내 표시와 앱 유지, 연속 두 번은 런처 복귀를 직접 확인했다.
- 이 에뮬레이터의 앱 화면에서 새 일반 계정 `codexqa0930app1` 가입 후 홈 이동을 확인했다. 저장 탭이 나타나 빈 `장소 보관함`이 열렸고, MY는 계정 닉네임·`아이언`·`현재 기여도 0`을 표시했다. 게시글·댓글·제보·문의 작성과 관리자 처리, 실제 점수 반영·승급 경계는 아직 확인하지 못했다.
