## 실행 결과와 제약

- 모바일: `npm test` 10개 통과, `npx tsc --noEmit` 통과, `npm run lint` 통과.
- 웹: 관련 6개 파일의 검사 24개 통과, `npm run build` 통과. 지도 SDK 키가 로컬 빌드 환경에 없어 실제 지도 렌더링은 검증하지 않았다.
- 현재 테스트 주소의 Django·Spring health, 장소 검색, 게시판 목록 확인은 모두 연결 실패. 운영 배포나 서버 변경은 실행하지 않았다.
- Django 사례 검사는 로컬 Python 환경에 Django가 없어 시작하지 못했다.
