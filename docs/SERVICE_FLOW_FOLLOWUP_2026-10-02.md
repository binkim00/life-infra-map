- 초기 500·느린 응답·인증 만료 검사는 앱 API 코드의 자동 검사였다. 아래 추가 점검에서는 동일 최종 APK의 에뮬레이터 실행 중 요청에만 일시적인 실패 응답을 공급하여 실제 화면까지 확인했다. 운영 서버 자체에 장애를 유발하지 않았다. 휴대폰에서 모든 장애 조합을 재현한 결과로 표현하지 않는다.

### 일반 계정 설정 추가 점검

- 카페 선호 태그 저장→앱 강제 종료·재실행→선택 해제에서 `선택을 해제했습니다.` 표시. 저장된 선택의 유지와 삭제를 확인하고 직접 선택은 원복했다.
- 서울 시청 공원 검색→검색 기록 목록→다시 검색에서 해당 검색어와 30곳 결과→기록 삭제 후 최신 실행 기록 사라짐을 확인했다. 반복 검색의 이전 기록은 별도 행으로 남는다.
- 새 댓글 알림·문의 답변 알림 두 설정을 켜짐→꺼짐으로 변경→앱 강제 종료·재실행 후 둘 다 꺼짐 유지→기존 켜짐으로 복원했다. 설정은 화면 안내처럼 이 기기의 알림 목록 표시 옵션이며 계정 간 서버 동기화 기능으로 해석하지 않는다.
