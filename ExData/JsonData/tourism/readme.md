# 관광공사 API 수집 데이터 설명

## tourist_spot_korea.json
- contentTypeId: 12
- 의미: 관광지 / 관광명소
- 활용 예시: 명소, 자연관광지, 역사 관광지, 사진 찍기 좋은 곳

## culture_korea.json
- contentTypeId: 14
- 의미: 문화시설
- 활용 예시: 박물관, 미술관, 전시관, 공연장

## festival_event_korea.json
- contentTypeId: 15
- 의미: 행사 / 공연 / 축제
- 활용 예시: 지역축제, 공연, 행사 정보

## travel_course_korea.json
- contentTypeId: 25
- 의미: 여행코스
- 활용 예시: 관광 코스, 산책 코스 후보, 데이트 코스 후보

## leports_korea.json
- contentTypeId: 28
- 의미: 레포츠
- 활용 예시: 체험, 스포츠, 야외활동, 액티비티

## accommodation_korea.json
- contentTypeId: 32
- 의미: 숙박
- 활용 예시: 호텔, 펜션, 숙소

## shopping_korea.json
- contentTypeId: 38
- 의미: 쇼핑
- 활용 예시: 시장, 쇼핑몰, 특산품 판매처

## tourism_all_except_food_korea.json
- 의미: 음식점을 제외한 위 7개 데이터를 합친 통합 파일
